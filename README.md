# Sorting Visualization Web Application

This project demonstrates and compares multiple sorting algorithms using an interactive web interface.
Users can enter numbers, compare sorting performance, and view step-by-step visualization of each sorting process.

## Features

* Bubble Sort
* Merge Sort
* Selection Sort
* Insertion Sort
* Quick Sort
* Sorting Time Comparison
* Fastest Algorithm Detection
* Step-by-Step Sorting Visualization
* Responsive UI Design
* Interactive “More Details” Page
* Back Navigation Support
* Dynamic Result Display

## Technologies Used

* HTML
* CSS
* JavaScript

## Functionalities Implemented

### Home Page

* Attractive landing page
* Navigation button to comparison page

### Comparison Page

* User input for numbers
* Executes all sorting algorithms
* Displays:

  * Sorted output
  * Execution time
  * Time complexity
* Shows fastest sorting algorithm

### More Details Feature

* Separate detailed page for every algorithm
* Displays sorting process step-by-step
* Example:

Before Sort:
5, 2, 8, 1

Step 1:
2, 5, 8, 1

Step 2:
2, 5, 1, 8

Final:
1, 2, 5, 8

### Responsive Design

* Works on desktop and mobile devices
* Glassmorphism UI design
* Smooth animations and hover effects
