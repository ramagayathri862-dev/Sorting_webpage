# Sorting Visualization Web Application

This project demonstrates and compares multiple sorting algorithms using an interactive web interface. Users can enter numbers, compare sorting performance, view execution times, and visualize the sorting process step-by-step. The application also provides detailed information about each sorting algorithm, making it useful for learning Data Structures and Algorithms (DSA).

## Features

* Bubble Sort
* Merge Sort
* Selection Sort
* Insertion Sort
* Quick Sort
* Sorting Time Comparison
* Fastest Algorithm Detection
* Step-by-Step Sorting Visualization
* Detailed Algorithm Information
* Responsive UI Design
* Interactive "More Details" Page
* Back Navigation Support
* Dynamic Result Display

### Comparison Page

* User input for numbers
* Executes all sorting algorithms
* Displays:

  * Sorted Output
  * Execution Time
  * Time Complexity

### More Details Feature

#### Step-by-Step Visualization

Displays how the array changes during the sorting process.

**Example:**

Before Sort: 5, 2, 8, 1

Step 1: 2, 5, 8, 1

Step 2: 2, 5, 1, 8

Final: 1, 2, 5, 8
